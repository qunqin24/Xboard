# Security policy

Use [private vulnerability reporting on GitHub](https://github.com/qunqin24/Xboard/security/advisories/new) for suspected vulnerabilities. Include the affected tag or commit, impact, relevant configuration, and steps to reproduce using test data. Redact passwords, API tokens, subscription links, and personal data.

If private vulnerability reporting is unavailable, use an existing private channel to contact a repository maintainer. Public issues are for general support and ordinary bugs.
